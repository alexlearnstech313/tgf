# TGF Skill Index

The full enumerated skill catalog for The Governance Framework. This is the externalized detail behind `CLAUDE.md` §9 — relocated here so the per-skill enumeration doesn't load into every session's context (the same rationale that moved §15–§22 to `docs/ARCHITECTURE.md`).

The operational summary — what a skill is, the catalog target, and how skills load — stays in `CLAUDE.md` §9. This document holds the complete list.

Skills live in `skills/` at the plugin root (per `DEC-2026-05-19-009`). Each skill is a complete governance unit with contextual triggers, authoritative source citations, numbered rules, anti-patterns with code examples, canonical patterns, AI-specific concerns, and workflow integration specifications. Skills include plain-language impact statements alongside citations.

Total catalog target: **~75 skills** across all phases (consolidated from ~80 per `DEC-2026-05-19-008` — architectural cluster 5→2, CIA triad 3→1). Adopter projects see only the subset their project mode + scope warrants.
