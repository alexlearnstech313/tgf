- **`docs/phase-4-plan.md` drafted (commit `50c1579`).** Phase 4 implementation plan covering: status against the architectural foundation (DEC-007/008/009), source verification per skill (NIST SSDF for CODE-QUALITY/CONTINUITY craft; OWASP Top 10:**2025** + ASVS 5.0 for SECURITY-CORE; ISO/IEC 27002 5.37 by-reference for CONTINUITY), per-skill mini-specs with target lengths and QC criteria (CODE-QUALITY, SECURITY-CORE, CONTINUITY each ≤300 lines SKILL.md + rules.md + anti-patterns.md reference files), implementation order, universal QC criteria (12 items including SKILL.md ≤300-line ceiling and ≤500-char description budget), five open Checkpoint 1 decisions (craft-vs-rule citation density, reference file scope, description style for always-on skills, review subagent scaffolds vs full, commit grouping with leans toward 6 focused commits). - **Phase 4 Checkpoint 1 cleared (2026-05-19, this commit).** All five decisions resolved. Decision A (citation density) reframed as "cite at the source's natural granularity" — refinement of DEC-004 Clause 2's intent; craft rules cite at principle level where no rule-level mapping exists. Decision B (reference file scope) = ship `rules.md` + `anti-patterns.md` per skill from day one; defer `citations.md` split until rules.md exceeds ~400 lines. Decision C (always-on skill descriptions) = descriptions serve both adoption modes (orchestrator-active + skills-only); target ~300-500 chars. Decision D (review subagent definitions) = scaffolds in Phase 4 (skills: preload + memory: project + 5-10 line system prompt); full system prompts deferred to Phase 11. Decision E (commit grouping) = six focused commits (template update → 3 skills → agents → closeout). None of A–E warranted a new ADR; tactical decisions captured in plan file. Phase 4 implementation cleared to begin with the template update.

- **`DEC-2026-05-19-007` added: TGF architecture as plugin with orchestrator agent.** Phase 4 deep research surfaced that Anthropic's Agent Skills spec is purely description-driven — there is no native `always-on: true` field. Three viable always-on mechanisms were considered; selected approach uses the Claude Code `--agent` flag with a custom orchestrator agent (`tgf-orchestrator`) that preloads CODE-QUALITY, SECURITY-CORE, and CONTINUITY via the Anthropic-native `skills:` frontmatter field. Plugin distribution is primary; standalone `.claude/` usage remains secondary. Review subagents (code-reviewer, security-auditor, red-team, holistic-reviewer) defined in `agents/` with per-subagent skill preloads and `memory: project` for self-evolution data accumulation. Replaces the SessionStart-hook injection approach proposed earlier — Anthropic provides the mechanism natively for agent contexts. `DEC-2026-05-17-003` Clause 1 is amended in effect: TGF-extension frontmatter fields (`sources`, `applies-when` sub-fields beyond `paths`, etc.) become TGF-internal metadata for Phase 11 meta-skill consumption, not Claude Code runtime fields. `.tgf/evolution/observations/` directory specified in `DEC-2026-05-17-003` Clause 4 is replaced by Anthropic's native `.claude/agent-memory/` mechanism; the `proposals/{pending,accepted,rejected}/` workflow stays TGF-internal.
- **`DEC-2026-05-19-008` added: Principled skill catalog consolidation.** Two consolidations: architectural cluster (5 skills `security-defense-in-depth` + `security-zero-trust` + `security-least-privilege` + `security-assumed-breach` → 1 `security-architectural-principles`; `security-secure-architecture` stays separate); CIA triad (3 skills → 1 `security-cia-triad`). Net reduction: ~80 → ~75 skills. Clusters NOT consolidated: IAM (4 skills stay split — highest-frequency domain), data layer (3 stay split), threat management (3 stay split). Establishes the reference-file pattern as standard: SKILL.md body ≤300 lines; verbose content (full rules, anti-patterns with code, citation tables) moves to `rules.md`, `anti-patterns.md`, `citations.md` reference files loaded on demand per Anthropic's spec. Solves citation density without dilution.
- **`DEC-2026-05-19-009` added: Hook physical layout amendment.** Amends `DEC-2026-05-17-005` for the physical layout (event taxonomy unchanged). TGF's distributed form uses plugin-native `hooks/hooks.json` (JSON configuration object) at the plugin root with hook scripts in `hooks/scripts/`. The PascalCase directory convention from DEC-005 remains valid for standalone `.claude/hooks/` usage but is not used in plugin distribution. Pre-Phase-4 housekeeping commit removes the empty `.claude/hooks/<EventName>/` placeholder directories.
- **Phase 4 research source verification (2026-05-19, per `DEC-2026-05-17-004`):** Verified via Claude's web tools: Anthropic Agent Skills authoring (frontmatter spec, ~1024 char description cap, ~1% skill-listing-budget context fraction, 500-line SKILL.md body recommendation, reference file pattern, skill content lifecycle with 25k token re-attachment budget after compaction); Claude Code Subagents (full frontmatter field list including `skills:` preload, `memory:`, `mcpServers:`, `hooks:`, `initialPrompt:`, `effort:`, `isolation:`, `--agent` flag for main-session use, subagents cannot spawn subagents constraint); Claude Code Plugins (manifest schema, plugin layout `skills/`+`agents/`+`hooks/hooks.json` at plugin root, `settings.json` with `"agent"` activation, background monitor capability, plugin namespace `/plugin-name:skill-name`); OWASP Top 10:2025 (released; SECURITY-CORE will cite 2025 not 2021 — new categories A03 Software Supply Chain Failures, A10 Mishandling of Exceptional Conditions; Security Misconfiguration moved from #5 to #2); agentskills.io open standard (cross-tool portability across ~40 AI tools including Cursor, OpenAI Codex, Gemini CLI, VS Code, GitHub Copilot; standard is description-driven only — TGF-specific features like `skills:` preload are Claude Code extensions).
