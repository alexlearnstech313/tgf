# Limitations

> Full version generated in Phase 15 (Documentation). Current entries are explicit limitations known and stated upfront.

## V1 Scope Boundaries

- **Solo developer / small team focus.** TGF's authority model treats the user as the project's stakeholder. Multi-team coordination patterns are not in v1.
- **No support guarantees.** TGF is a personal project. Issues and PRs may be reviewed at the author's discretion; no SLA.
- **Schema and structure may evolve in v2.** V1's Phase 0 interface decisions are locked, but the project is young — expect breaking changes between v1.x releases until v2 stabilizes.
- **Compliance regulatory skills cover GDPR, CCPA, HIPAA, PCI-DSS, SOC 2.** Other regimes (FedRAMP, FERPA, GLBA, ISO 27001 certification-grade depth, etc.) are out of v1 scope; SKILL-FORGE can generate them per project as needed.
- **English only.** Framework content and interaction language is English. Localization is not in v1 scope.
- **No production-system operation guarantees.** TGF is a governance framework, not a runtime system. It informs how AI-assisted development happens; it doesn't run your application.

## What TGF Doesn't Do

- TGF does not write code that doesn't need to be written. Standards within scope are unconditional; out-of-scope work is out of scope.
- TGF does not override the user's decisions. The user is the project's stakeholder; TGF advises, surfaces concerns, and documents disagreement but defers.
- TGF does not replace domain experts. Domain research grounds work in published understanding but is not a substitute for clinicians, attorneys, accountants, or other specialists when the project warrants them.
- TGF does not enforce compliance certifications. The framework helps produce audit-ready work; actual certification requires qualified auditors.

## Realistic Adoption Expectations

TGF is one entrant in a competitive space (Superpowers, great_cto, and other Claude Code governance frameworks). It differentiates on authoritative-source discipline, granular skills with anti-pattern catalogs, vibe-coder accessibility, and mode-aware operation. Most projects will not need everything TGF offers; most users will engage with a subset.
